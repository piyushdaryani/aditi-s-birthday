Supported formats: JPG, JPEG, PNG, WebP, AVIF.

### Mobile Optimization Recommendations:
1. Resize photos to approximately 800px - 1000px width.
2. Compress each image to under 250KB (using tools like Squoosh, TinyPNG, or ImageOptim).
3. Avoid uploading raw 5MB-10MB mobile phone camera images directly to keep mobile loading lightning fast!
4. If a custom photo is missing, high-aesthetic curated fallback photography is automatically displayed.
